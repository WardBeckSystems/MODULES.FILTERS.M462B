# Ward-Beck Systems M462B Parametric Equalizer VST/AU Plugin

**Hardware Unit:** Ward-Beck Systems M462B 4-Band Parametric Equalizer (Drawing `462-02-003`, ca. 1975)  
**Format:** VST3, AU, AAX (C++20 / JUCE 7)  
**Core Shared Engine:** [`wbs_core`](file:///home/anthony/Documents/GitProjects/WBSps.ca/2030.env/vst/core/README.md)

---

## Technical Specifications
- **Low Band:** $30\text{ Hz}$ to $400\text{ Hz}$, switchable Shelf/Bell, $\pm15\text{ dB}$.
- **Low-Mid Band:** $100\text{ Hz}$ to $1.6\text{ kHz}$, continuous $Q$ ($0.5$ to $3.0$), $\pm15\text{ dB}$.
- **High-Mid Band:** $800\text{ Hz}$ to $12.8\text{ kHz}$, continuous $Q$ ($0.5$ to $3.0$), $\pm15\text{ dB}$.
- **High Band:** $1.5\text{ kHz}$ to $18.0\text{ kHz}$, switchable Shelf/Bell, $\pm15\text{ dB}$.
- **Console Headroom Modeling:** Switchable $\pm15\text{V}, \pm22\text{V}, \pm25\text{V}$ rail supply headroom limits.
